---
name: Wallet section tab sizing
description: User-specified dimensions for the Wallet Overview, Deposit, Withdraw, and History tabs.
---

Wallet section tabs use a minimum height of 44 px, 16 × 16 px icons, 12 px labels, 16 px horizontal padding on each side, and an 8 px icon-to-label gap. Tab widths are content-based rather than fixed.

**Why:** The user specified these exact values for visual consistency on the Wallet page.

**How to apply:** Preserve these measurements and intrinsic content sizing in desktop and responsive Wallet tab styles.
